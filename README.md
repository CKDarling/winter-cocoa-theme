# Winter Cocoa — VS Code Theme

## Install

Search for **Winter Cocoa** in the Extensions view, or run:

```bash
code --install-extension CKinkadeDarling.winter-cocoa
```

Then press `Cmd+K Cmd+T` (`Ctrl+K Ctrl+T` on Windows/Linux) and pick **Winter Cocoa**.
